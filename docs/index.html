🏏 Cricket Player Management API

Welcome to the Cricket Player Management API

A comprehensive GraphQL API designed for managing cricket players and teams in the Indian Premier League (IPL). This API provides powerful operations to create, read, update, and query player information with real-time data access.

🚀 Key Features

  • Player Management: Create and manage cricket player profiles
  • Team Operations: Handle team assignments and queries
  • Real-time Queries: Fast and efficient data retrieval
  • Type Safety: Strongly typed GraphQL schema
  • Interactive Documentation: Built-in query explorer

🏆 Supported Teams

  • CSK - Chennai Super Kings
  • MI - Mumbai Indians
  • RCB - Royal Challengers Bangalore
  • DC - Delhi Capitals
  • GT - Gujarat Titans

📚 Getting Started

Use the interactive query builder below to explore the API. All operations are documented with examples and response formats.

Example Query

query GetAllPlayers {
  findAll {
    id
    name
    team
    city
  }
}

🔧 API Endpoint

  • GraphQL Endpoint: http://localhost:8080/graphql
  • Method: POST
  • Content-Type: application/json

Queries

findAll

Description

Retrieves all cricket players from the database. Returns a list of all players with their basic information including ID, name, team, and city.

Response

Returns [Player]

Example

Query
query findAll {
  findAll {
    id
    name
    team
    city
  }
}
Response
{
  "data": {
    "findAll": [
      {
        "id": "4",
        "name": "xyz789",
        "team": "CSK",
        "city": "xyz789"
      }
    ]
  }
}
Queries

findById

Description

Finds a specific cricket player by their unique ID. Returns the player details if found, or null if the player doesn't exist.

Args: id: The unique identifier of the player to retrieve

Response

Returns a Player

Arguments
Name Description
id - ID!

Example

Query
query findById($id: ID!) {
  findById(id: $id) {
    id
    name
    team
    city
  }
}
Variables
{"id": 4}
Response
{
  "data": {
    "findById": {
      "id": "4",
      "name": "xyz789",
      "team": "CSK",
      "city": "xyz789"
    }
  }
}
Queries

findByTeam

Description

Retrieves all players belonging to a specific IPL team. Useful for getting team rosters and analyzing team compositions.

Args: team: The team abbreviation (CSK, MI, RCB, DC, or GT)

Response

Returns [Player]

Arguments
Name Description
team - Team!

Example

Query
query findByTeam($team: Team!) {
  findByTeam(team: $team) {
    id
    name
    team
    city
  }
}
Variables
{"team": "CSK"}
Response
{
  "data": {
    "findByTeam": [
      {
        "id": 4,
        "name": "xyz789",
        "team": "CSK",
        "city": "abc123"
      }
    ]
  }
}

Mutations

createPlayer

Description

Creates a new cricket player in the system. All required fields must be provided to successfully create a player.

Args: name: The full name of the player (required) team: The IPL team the player belongs to (required) city: The city associated with the player (optional)

Returns: The newly created player object with assigned ID

Response

Returns a Player

Arguments
Name Description
name - String!
team - Team!
city - String!

Example

Query
mutation createPlayer(
  $name: String!,
  $team: Team!,
  $city: String!
) {
  createPlayer(
    name: $name,
    team: $team,
    city: $city
  ) {
    id
    name
    team
    city
  }
}
Variables
{
  "name": "abc123",
  "team": "CSK",
  "city": "xyz789"
}
Response
{
  "data": {
    "createPlayer": {
      "id": 4,
      "name": "xyz789",
      "team": "CSK",
      "city": "xyz789"
    }
  }
}
