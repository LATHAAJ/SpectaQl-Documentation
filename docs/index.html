Player Management API

A GraphQL API for managing cricket players and teams. This API provides operations to create, read, and query player information.

API Endpoints
http://localhost:8080/graphql
Version

1.0.0

Queries

findAll

Response

Returns [Player]

Example

Query
query findAll {
  findAll {
    id
    name
    team
    city
  }
}
Response
{
  "data": {
    "findAll": [
      {
        "id": "4",
        "name": "xyz789",
        "team": "CSK",
        "city": "xyz789"
      }
    ]
  }
}

createPlayer

Response

Returns a Player

Arguments
Name Description
name - String!
team - Team!
city - String!

Example

Query
mutation createPlayer(
  $name: String!,
  $team: Team!,
  $city: String!
) {
  createPlayer(
    name: $name,
    team: $team,
    city: $city
  ) {
    id
    name
    team
    city
  }
}
